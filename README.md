Arduino Sandbox

#Overview:
This website allows user to understand an Arduino UNO board before getting and testing it.
It explains about the functions and type of pins and also lets them connect the wire to 
see if its safe to do it or not. Also it lets the user to wirte the code without needing
 any external software and simulate it with other components like: servo motors, leds, etc.


#progress till now:
Right now I have built the inspect mode to learn about the pins and you can connect the
